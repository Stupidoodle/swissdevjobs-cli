# CV conventions — Switzerland (`ch`)

Applies to: swissdevjobs, jobsch, jobup.

## Format

- **2 pages is normal, 3 acceptable for senior profiles.** The US one-page
  rule does not apply. Long-form, information-dense CVs (LaTeX
  moderncv/awesome-cv style) are well received in tech and have a track
  record of winning interviews here — don't compress a strong CV to fit an
  American template.
- Tabular "Lebenslauf" structure is the default in German-speaking
  Switzerland: clear reverse-chronological blocks with month/year ranges.
  Gaps get noticed; explain them in one line rather than hiding them.
- Photo: **still common and expected by traditional employers** (banking,
  insurance, public sector, healthcare), increasingly optional in tech and
  at international companies. Include one for conservative industries on
  jobs.ch/jobup.ch; skip it for startups and US-headquartered firms. A
  photo, if used, is a professional headshot — never a crop.

## Content expectations

- **Work permit / nationality up front.** State citizenship and, for
  non-Swiss, the permit (B/C/L or "EU/EFTA citizen — no permit required").
  Recruiters filter on this before anything else; omitting it costs
  interviews.
- **Language skills with levels, always.** CEFR levels (C1, B2) or
  native/fluent per language. In Switzerland this section is read, not
  skimmed — German for Deutschschweiz roles, French for Romandie
  (jobup.ch), English for international teams.
- Date of birth and marital status: traditional employers still expect
  them; tech increasingly doesn't. Follow the industry of the posting.
- **Zeugnisse (reference letters) exist here.** Don't attach them
  unprompted to a first application, but state "Referenzen und
  Arbeitszeugnisse auf Anfrage" and have the user keep them ready — Swiss
  employers actually request them.

## Language rules

- Posting in German → German CV and letter (Sie-Form, no exceptions).
- Posting on jobup.ch or a Romandie location → French.
- Posting in English → English, even from a Swiss company.

## Motivation letter

- Formal salutation with a name whenever the posting has a contact person
  ("Sehr geehrte Frau X" / "Madame, Monsieur").
- Swiss letters are sober: concrete fit, no superlatives, under one page.
- Mention the permit situation again in one clause if the user is
  non-Swiss — the letter is often read before the CV.
