# CV conventions — Germany (`de`)

Applies to: germantechjobs.

## Format

- **Tabular Lebenslauf, reverse-chronological, 2 pages.** Germany invented
  the format everyone else calls "the German CV": clean two-column blocks,
  month/year ranges, no prose paragraphs.
- Photo: legally optional since the AGG (anti-discrimination law) and
  genuinely optional in tech — but a large share of traditional Mittelstand
  employers still expect one. Include for conservative industries, skip for
  startups; never let a bad photo in.
- Word-template culture is real outside tech; inside tech a clean LaTeX or
  typst CV reads as a signal, not a violation.
- Signature + date at the bottom of the CV is a traditional touch some
  employers still expect ("Ort, Datum, Unterschrift") — harmless to
  include in conservative applications, safe to drop in tech.

## Content expectations

- **Work authorization**: EU citizens state citizenship; non-EU state the
  permit/Blue Card status explicitly. Same filter logic as Switzerland.
- Language skills with CEFR levels. German level matters even for
  English-speaking roles — B2+ opens doors, and claiming more than the
  user has backfires in the phone screen.
- The classic full application ("Bewerbungsmappe": letter + CV +
  Zeugnisse + certificates) still exists in conservative sectors. For
  tech postings a CV + letter is enough, with "Zeugnisse auf Anfrage".
- Grades and degree details carry more weight than in anglo markets —
  include the degree, institution, and final grade if decent.

## Language rules

- German posting → German documents (Sie-Form).
- English posting → English documents; note German level in the CV.

## Motivation letter (Anschreiben)

- Still expected in Germany far more than elsewhere. One page, formal,
  concrete: why this company, why this role, what the user brings —
  in that order, no generic openings ("hiermit bewerbe ich mich" is
  filler; start with substance).
- "Sehr geehrte/r Frau/Herr X" with a real name whenever findable;
  "Sehr geehrte Damen und Herren" only as last resort.
