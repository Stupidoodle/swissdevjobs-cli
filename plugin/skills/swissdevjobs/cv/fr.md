# CV conventions — France (`fr`)

Applies to: devitjobs-fr.

## Format

- **One page is the strong norm** for a French CV, two for senior
  profiles. Density over length.
- Photo: traditionally common, now genuinely optional and declining in
  tech. Include only if the user wants to; never for US-headquartered
  companies hiring in France.
- Personal details header is fuller than anglo CVs: age or birth year
  still appears frequently, as do driving licence and city — follow the
  user's comfort, none are mandatory.

## Content expectations

- **Work authorization**: EU citizens state citizenship; non-EU state the
  titre de séjour / passeport talent status explicitly.
- Section labels in French matter when writing French ("Expérience
  professionnelle", "Formation", "Compétences", "Langues").
- Education carries unusual weight in France — school names (and
  "grandes écoles" if applicable) go prominently, even for experienced
  profiles.
- Language levels: CEFR, with honest French level front and center for
  non-natives; many French teams work in French even when the posting is
  in English.

## Language rules

- French posting → French documents; the register is formal
  (vouvoiement, "Madame, Monsieur" when no name is known).
- English posting → English CV, but a French-language one-liner about
  the user's French level helps.

## Lettre de motivation

- Still a genuine institution in France: formal structure
  (vous / moi / nous — the company, the candidate, the fit together),
  one page, formal closing formula ("Je vous prie d'agréer…" or a
  lighter "Cordialement" in tech).
- Tech startups increasingly skip it — write one when the posting asks
  or the company is traditional.
